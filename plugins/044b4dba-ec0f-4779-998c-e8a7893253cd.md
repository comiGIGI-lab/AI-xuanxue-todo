# Chat Completions API Documentation

---

## Meta

- **title**: Chat Completions API
- **method**: POST
- **path**: /compatible-mode/v1/chat/completions
- **base_url**: https://creo4u.com/autoagent/api/proxy/044b4dba-ec0f-4779-998c-e8a7893253cd
- **auth_type**: Bearer Token
- **content_type**: application/json

---

## Description

大语言模型的OpenAI兼容对话接口。支持Qwen系列商业版和开源版模型。提供多轮对话、流式输出、工具调用(Function Calling)、联网搜索、代码解释器、结构化输出等高级功能。

**典型应用场景**:
- 智能客服对话系统
- 代码生成与解释
- 图像理解与分析
- 联网实时信息查询
- 结构化数据提取

**前置条件**:
- 需要有效的API Key
- 选择支持的模型名称

---

## Authentication

**认证方式**: Bearer Token

**参数位置**: HTTP Header

**Header名称**: `Authorization`

**值格式**: `Bearer ${{CREO4U_API_KEY}}`

**获取方式**: 环境变量获取

**有效期**: 长期有效,建议定期轮换

**注意**: 服务调用时,请在Authorization Header中发送`${{CREO4U_API_KEY}}`,CREO4U_API_KEY从环境变量中获取

## Request Body

**Content-Type**: application/json

| 字段名 | 类型 | 必填 | 默认值 | 约束 | 示例值 | 说明 |
|--------|------|------|--------|------|--------|------|
| model | string | 是 | - | 支持的模型列表见文档 | "qwen3.5-plus" | 模型名称,仅支持qwen3.5-plus大语言模型 qwen3.5-plus |
| messages | array | 是 | - | 至少包含一条user消息 | 见下方消息格式 | 对话上下文,按时间顺序排列 |
| stream | boolean | 否 | false | true/false | true | 是否流式输出,建议设为true提升体验 |
| stream_options | object | 否 | - | 仅stream=true时生效 | {"include_usage":true} | 流式输出配置 |
| temperature | float | 否 | 模型默认值 | [0, 2) | 0.7 | 采样温度,控制输出多样性 |
| top_p | float | 否 | 模型默认值 | (0, 1.0] | 0.8 | 核采样概率阈值 |
| top_k | integer | 否 | 模型默认值 | ≥0,>100则禁用 | 50 | 候选Token数量 |
| max_tokens | integer | 否 | 模型最大输出长度 | 正整数 | 2000 | 限制输出的最大Token数 |
| presence_penalty | float | 否 | 模型默认值 | [-2.0, 2.0] | 0.5 | 控制内容重复度,正值降低重复 |
| response_format | object | 否 | {"type":"text"} | text/json_object/json_schema | {"type":"json_object"} | 返回内容格式 |
| n | integer | 否 | 1 | [1, 4] | 1 | 生成响应的数量 |
| stop | string/array | 否 | - | 字符串或token_id数组 | ["\n\n","结束"] | 停止词,遇到时终止生成 |
| seed | integer | 否 | 随机 | [0, 2³¹-1] | 12345 | 随机数种子,用于结果复现 |
| logprobs | boolean | 否 | false | true/false | false | 是否返回Token对数概率 |
| top_logprobs | integer | 否 | 0 | [0, 5] | 3 | 返回最大概率的候选Token数 |
| tools | array | 否 | - | Function对象数组 | 见工具调用示例 | Function Calling工具列表 |
| tool_choice | string/object | 否 | "auto" | auto/none/指定函数 | "auto" | 工具选择策略 |
| parallel_tool_calls | boolean | 否 | false | true/false | false | 是否并行调用工具 |
| enable_search | boolean | 否 | false | true/false | true | 是否开启联网搜索 |
| search_options | object | 否 | - | 联网搜索配置 | {"forced_search":true} | 搜索策略配置 |
| enable_thinking | boolean | 否 | 模型默认值 | true/false | true | 是否开启思考模式(Qwen3.5/3/3-VL) |
| thinking_budget | integer | 否 | 模型最大值 | 正整数 | 5000 | 思考过程最大Token数 |
| enable_code_interpreter | boolean | 否 | false | true/false | true | 是否开启代码解释器 |
| vl_high_resolution_images | boolean | 否 | false | true/false | true | 是否提升图像像素上限至16384 Token |
| modalities | array | 否 | ["text"] | ["text"]/["text","audio"] | ["text","audio"] | 输出模态(Qwen-Omni) |
| audio | object | 否 | - | 音频配置 | {"voice":"alloy"} | 输出音频配置(Qwen-Omni) |

**messages数组元素格式**:

**System Message** (可选):
```json
{
  "role": "system",
  "content": "You are a helpful assistant."
}
```

**User Message** (必填):
```json
{
  "role": "user",
  "content": "你是谁?"
}
```
或多模态输入:
```json
{
  "role": "user",
  "content": [
    {"type": "text", "text": "这张图片里有什么?"},
    {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
  ]
}
```

**Assistant Message** (可选,用于多轮对话):
```json
{
  "role": "assistant",
  "content": "我是千问,阿里云开发的AI助手。"
}
```

**Tool Message** (可选,工具调用结果):
```json
{
  "role": "tool",
  "tool_call_id": "call_abc123",
  "content": "{\"result\": \"success\"}"
}
```

## Response Definition

### 非流式输出响应

| 字段名 | 数据类型 | 始终返回 | 空值行为 | 说明 |
|--------|----------|----------|----------|------|
| id | string | 是 | - | 本次调用唯一标识符 |
| object | string | 是 | - | 固定值"chat.completion" |
| created | integer | 是 | - | 请求创建的Unix时间戳(秒) |
| model | string | 是 | - | 使用的模型名称 |
| system_fingerprint | string \| null | 是 | null | 当前固定为null |
| choices | array | 是 | - | 模型生成内容数组 |
| choices[].index | integer | 是 | - | 响应索引,从0开始 |
| choices[].message | object | 是 | - | 助手消息对象 |
| choices[].message.role | string | 是 | - | 固定值"assistant" |
| choices[].message.content | string \| null | 是 | 工具调用时为null | 生成的文本内容 |
| choices[].message.reasoning_content | string \| null | 否 | 未开启思考时不返回 | 思考过程内容(enable_thinking=true) |
| choices[].message.tool_calls | array \| null | 否 | 无工具调用时为null | 工具调用信息 |
| choices[].message.audio | object \| null | 否 | 非音频输出时不返回 | 音频输出信息(Qwen-Omni) |
| choices[].finish_reason | string | 是 | - | 停止原因:stop/length/tool_calls/content_filter |
| choices[].logprobs | object \| null | 是 | logprobs=false时为null | Token对数概率信息 |
| usage | object | 是 | - | Token消耗统计 |
| usage.prompt_tokens | integer | 是 | - | 输入Token数 |
| usage.completion_tokens | integer | 是 | - | 输出Token数 |
| usage.total_tokens | integer | 是 | - | 总Token数 |
| usage.prompt_tokens_details | object \| null | 否 | - | 输入Token详情 |
| usage.prompt_tokens_details.cached_tokens | integer | 否 | 无缓存时为0 | 缓存命中的Token数 |

### 流式输出响应 (stream=true)

每个数据块(chunk)格式:

| 字段名 | 数据类型 | 始终返回 | 说明 |
|--------|----------|----------|------|
| id | string | 是 | 本次调用唯一标识符(所有chunk相同) |
| object | string | 是 | 固定值"chat.completion.chunk" |
| created | integer | 是 | 请求创建时间戳(所有chunk相同) |
| model | string | 是 | 使用的模型名称 |
| system_fingerprint | string \| null | 是 | 固定为null |
| choices | array | 是 | 最后一个chunk(include_usage=true)时为空数组 |
| choices[].index | integer | 是 | 响应索引 |
| choices[].delta | object | 是 | 增量内容 |
| choices[].delta.role | string \| null | 否 | 首个chunk为"assistant",后续为null |
| choices[].delta.content | string \| null | 否 | 增量文本内容 |
| choices[].delta.reasoning_content | string \| null | 否 | 增量思考内容 |
| choices[].delta.tool_calls | array \| null | 否 | 增量工具调用信息 |
| choices[].finish_reason | string \| null | 是 | 生成中为null,结束时为stop/length等 |
| choices[].logprobs | object \| null | 是 | Token对数概率 |
| usage | object \| null | 否 | 仅最后一个chunk(include_usage=true)返回 |

## Error Responses

| HTTP状态码 | 错误码 | 触发原因 | 处理建议 |
|------------|--------|----------|----------|
| 400 | InvalidParameter | 请求参数格式错误或缺少必填参数 | 检查请求体格式,确保model和messages字段正确 |
| 400 | InvalidApiKey | API Key无效或已过期 | 检查Authorization Header中的API Key是否正确 |
| 400 | ModelNotFound | 指定的模型不存在 | 使用支持的模型名称 |
| 400 | ContentPolicyViolation | 输入或输出内容违反安全策略 | 修改输入内容,避免敏感信息 |
| 429 | RateLimitExceeded | 超过API调用频率限制 | 降低请求频率,建议指数退避重试,间隔1-60秒 |
| 429 | QuotaExceeded | 账户配额不足 | 充值或升级套餐 |
| 500 | InternalError | 服务器内部错误 | 可重试,建议间隔5-30秒,最多重试3次 |
| 503 | ServiceUnavailable | 服务暂时不可用 | 可重试,建议间隔10-60秒 |
| 504 | Timeout | 请求超时 | 可重试,或减少max_tokens降低生成长度 |

## Request Examples

### 基础对话调用
```bash
curl -X POST https://creo4u.com/autoagent/api/proxy/044b4dba-ec0f-4779-998c-e8a7893253cd/compatible-mode/v1/chat/completions \
  -H "Authorization: Bearer ${{CREO4U_API_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.5-plus",
    "enable_thinking": false,
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "你是谁?"}
    ]
  }'
```
